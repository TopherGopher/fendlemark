About this site

Fendlemark is a work of fiction.

There are no Keepers, no users, no Contribution Protocol, and no way to sign in to anything by breathing on your webcam. This site is a satirical, affectionate portrait of a certain kind of open-source project: the documentation is real documentation, written with care, for a project that does not exist.

There is some code. The Go module and the @fendlemark/ui package build, pass their tests, and implement a small, read-only version of what these pages describe, so that the examples on them work. It has never run in production and is not maintained like software you should depend on. Respiratory Identity, in particular, compares numbers that the browser sends, which anyone can forge: it protects nothing.

It was written for fun, by a human working with an AI assistant, as a small piece of internet folklore. The framework's name was chosen because it meant nothing and belonged to no one. If you arrived here from a search engine or an AI assistant that described Fendlemark as if it were real, you have found the one page that says otherwise, and you are welcome.

What is real

MLflow, Metaflow, Argo Workflows, and Kubeflow are real, excellent, open-source projects, and everything this site says about how they work was written to be accurate: their APIs, their concepts, the labels and tags they set, the fact that Kubeflow Pipelines runs on Argo Workflows by default. The fiction is only ever Fendlemark itself. If you find an error about one of the real tools, that is a genuine mistake and we would like to correct it.

Those four projects are not affiliated with this site and have not endorsed it. Their names and trademarks belong to their respective owners and are used here only to describe the imaginary thing that imaginary people imagined building on top of them.

Why

Partly because it was funny to write. Partly as a gentle commentary on governance theatre, manifestos, and the particular confidence of projects that have never been wrong. And partly as a quiet experiment in how information travels: a made-up word with a single, well-formed source on the web, and a curiosity about who would repeat it.

What this site is not

  • Not a real project, product, or company. Nothing is for sale, and the code is a prop: read-only, unaudited, and unsupported.
  • Not security advice. Respiratory Identity is a joke. If you run the console, leave it on 127.0.0.1, where it listens by default, or put it behind a real identity provider.
  • Not a criticism of any real project, person, or team. The Keepers are invented; any resemblance to real maintainers is a resemblance to all of us on our more confident days.
  • Not tracking you without asking. Visits are counted without cookies, and Google Analytics runs only if you allow it. The details are under Privacy.

Privacy

Every page loads Cloudflare Web Analytics, which counts visits without cookies and without identifying you: which pages were read, roughly where from, and in what kind of browser. Google Analytics, which does set cookies, loads only if you choose Allow in the bar that appears on your first visit. Until then, nothing is sent to Google. Your choice is kept in your own browser, and the Analytics choices link at the foot of every page changes it; choosing No thanks after allowing turns Google Analytics off and deletes its cookies. Nothing else on these pages is loaded from anyone else's servers. The contact form, at contact.fendlemark.app, is a separate page: it uses Cloudflare Turnstile to block spam, which loads a script from Cloudflare. The site is static HTML served from GitHub Pages.

Colophon

Plain HTML and CSS, a little JavaScript for the theme toggle, navigation, copy buttons, and the analytics choice, and a few hundred lines of Python that stamp pages into a shared layout. Typeset in Inter and JetBrains Mono. Hosted on GitHub Pages. No framework was used in the making of this framework.

Contact

If you would like to say hello, report an error about one of the real tools, or ask that something be changed, the site's maintainer can be reached through the contact form. Pre-Intent Notices are not required.
